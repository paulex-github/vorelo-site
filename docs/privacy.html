Website privacy

This note describes the static Vorelo documentation website. It is not a privacy policy for job boards operated by people who install the plugin.

What this site's code does

These pages contain no analytics scripts, forms, advertising, embedded videos, remote fonts or browser storage code. The website itself does not set cookies or collect CVs, applications or account registrations.

GitHub Pages hosting

The website is served by GitHub Pages. GitHub states that visitor IP addresses are logged and stored for security purposes, regardless of whether the visitor is signed in. See GitHub Pages data collection information and the GitHub Privacy Statement for its processing and available privacy rights.

External links and public feedback

Following a link to GitHub or WordPress.org takes you to a separate service with its own privacy practices. Support forum posts and repository content can be public. Do not include personal data, credentials or CVs in feedback.

For questions about this documentation, use the public website issue tracker without posting sensitive information.

If you run a job board

The site operator is responsible for explaining their own collection, use and retention of candidate and employer information, their hosting and email services, and how individuals can exercise their rights. Installing Vorelo does not automatically make a site compliant with privacy law.
